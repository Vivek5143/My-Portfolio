## 🌟 Key Projects Showcased

1.  **CampusPal (AI Campus Assistant)**
    *   An AI-powered campus assistant designed for APSIT using Retrieval-Augmented Generation (RAG) with FAISS indexing.
    *   *Tech Stack:* React 19, FastAPI, LangChain, Groq LLM, FAISS, Docker, Hugging Face.
2.  **EduDiff (GenAI Math Animator)**
    *   Transforms natural language prompts into animated math lessons or specialized video explanations.
    *   *Tech Stack:* Next.js, Flask, Manim engine, Google Gemini API, Docker, Python.
3.  **TransactAI (Hybrid Transaction Categorizer)**
    *   Production-grade transaction categorization using deterministic heuristics, fine-tuned DistilBERT models, and SentenceTransformers.
    *   *Tech Stack:* FastAPI, PostgreSQL, PyTorch, DistilBERT, Next.js, Kotlin (Android), Docker.
4.  **InstaClaim (Offline Insurtech Claim Processor)**
    *   A privacy-first offline insurtech claim processing assistant that extracts and analyzes insurance documents.
    *   *Tech Stack:* Streamlit, LangChain, Ollama (Phi3), Tesseract OCR, Python.
5.  **Multi-Agent Platform (CrewAI Workflow Platform)**
    *   Orchestrates multiple specialized AI agents using CrewAI to execute complex sequential workflows.
    *   *Tech Stack:* CrewAI, Google Gemini, Ollama, Python, Pygame.
6.  **Interview Assistant (Voice-First Interview Simulator)**
    *   An interactive, voice-first simulator using real-time Speech-to-Text (AssemblyAI) and Text-to-Speech (Murf AI) with conversational history via LangGraph.
    *   *Tech Stack:* Flask, Python, Google Gemini, AssemblyAI, Murf AI, LangGraph.
7.  **Daily-Work-Logger**
    *   Natural language parsing logger synchronizing daily activities to cloud spreadsheets (Google Sheets API).
    *   *Tech Stack:* Streamlit, Python, Google Sheets API, Google Gemini API.

## 🚀 Getting Started Locally

Follow these steps to run the portfolio locally:

### 1. Clone the repository
```bash
git clone https://github.com/Vivek5143/My-Portfolio.git
cd My-Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Build for Production
```bash
npm run build
```
The production-ready static files will be generated in the `dist/` directory.
